# 🥒 PICKLE VST3 Plugin - Ready to Use! 
 
This package contains everything you need for PICKLE VST3! 
 
## Features: 
- Pickle Processor: OTT-style multiband compression 
- Pickle Crunch: Enhanced distortion with low/high focus 
- Pickle Bitcrush: Subtle bit reduction (below Crunch knob) 
- Beautiful blurred glass UI 
- Smart installer with version detection 
 
## To Build the Actual Plugin: 
1. Install Visual Studio 2022 Community (free) 
2. Install CMake and add to PATH 
3. Run: installer\build_all.bat 
 
## Quick Start: 
- Check: installer\check_requirements.bat 
- Build: installer\setup_and_build.bat 
- Install: installer\package\install.exe
